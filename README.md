# Stephen J. Owojori — Digital Marketing Portfolio

Static single-page portfolio. Open `index.html` locally, or deploy to any static host.

## Structure
- `index.html` — the portfolio (self-contained, no build step)
- `reports/` — downloadable GA4 / SEO summary PDFs linked from the case studies
- `vercel.json` — Vercel config (clean URLs)

## Deploy
Connected to Vercel via GitHub: every push to `main` redeploys automatically.
